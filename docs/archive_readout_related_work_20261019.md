# 完整存档与动作条件读取：查重和主张边界

检索日期：2026-10-19。这是有范围的原始论文核查，不能当作穷尽引用关系，也没有证明新主张可发表。下表区分论文已有内容与本项目据此作出的判断。

| 原始来源 | 已覆盖的内容 | 对本项目的约束 |
| --- | --- | --- |
| [EventVLA，v3](https://arxiv.org/html/2606.20092v3) | 利用动作相关表征预测未来事件位置，写入关键帧并与时间锚点共同读取 | “记忆模块看动作”本身不是新贡献；需区分写入、读取和物理重新观测 |
| [MemoryVLA](https://arxiv.org/abs/2508.19236) | 感知及认知记忆检索与融合 | “给 VLA 加检索”不足以形成区别 |
| [Mem-World，v3 摘要](https://arxiv.org/abs/2606.18960v3) | 以未来动作为条件，基于几何与时空表面索引检索历史，服务世界模型生成 | “根据拟执行动作选择历史”已经被提出；改用于策略头不自动构成研究贡献 |
| [FlashBack](https://arxiv.org/abs/2610.01192) | 在历史检索前判断是否需要回忆，使用隔离的 Recall 路径接入历史 | 读取触发器、只读历史上下文不是新概念；它研究流式视觉语言模型，不等于已经解决机器人闭环问题 |
| [Memory for Attention，v2](https://arxiv.org/abs/2607.23797v2) | 在感知预算下，按语言相关性和变化历史安排重新感知，并比较时序规则 | “有限预算下选择回看什么”也有直接先例；强时序与相关性基线必须保留 |
| [ActiveArena，v2](https://arxiv.org/abs/2609.24124v2) | 主动取证、多轮记忆推理，比较写入、容量和规划器指导记忆等因素 | 可以检查已有任务是否提供研究条件；不能把再建一个遮挡场景当作贡献 |

**本项目的推断：新方向存在明显重叠，目前没有充分依据宣称方法创新。** 尚可检验的是更窄的闭环因果问题：给定相同可用历史、查询和总预算，改变拟执行动作是否改变证据的控制价值，学习方法是否利用了这种变化，且超过公开动作规则与单次检索。这个问句仍不是已经成立的独有贡献。

必须分开两类实验：

1. 因果归因：各方法共享同一个仅用公共锚点生成的动作提议；查询、状态、模型和随机数相同。比较无动作、正确动作、打乱动作和强动作规则，动作提议成本对所有方法计入。
2. 实际部署：保留无需额外动作提议的单次查询检索，以及预算容许时一次读全的基线；比较完整成功率—耗时曲线。不能强迫这类基线执行一个不需要的前向，再宣称方法有效率优势。

先生成动作、再选择历史会引入循环与额外前向：如果从已读全部历史的动作中取特征，相当于免费使用了证据；如果真正重跑一个锚点动作头，就必须支付成本。已有快照的执行动作不能冒充新的、未读历史的动作提议。本轮代码拒绝把缓存动作或缺少推理耗时的输入记录当作有效闭环提议。

正式模型还没有接入这条新路径，当前仅复用了上游输入构造和处理器。下一项研究产出必须是一例有原始观测证据、能排除强规则的真实预算失败；若找不到，就结束本路线，不能继续把接口审计数量当研究进展。
