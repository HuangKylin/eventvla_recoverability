## 空槽和预算

空槽保留原位置、时间和视角元数据，图像为约定的缺失输入表示，不声称是对应时刻的真实观察。原候选图像从策略记忆删除；缓存、待提交动作和服务端记忆按所有分支相同规则清空，逐请求检查旧图像没有从任何输入通道回流。空槽不含原图内容，但仍占用一个图像输入位置；后续预算须同时报告实际保留证据字节、槽位元数据和模型图像 token 成本。

正常的新事件写入保留，使用原生 FIFO 规则限制为四个位置。新事件可挤出最老的旧事件或空槽；首次请求固定原有四个位置，后续位置随原生提交推进。所有固定容量分支的每个实际请求都必须恰好含四张事件图像。该版本不增加模型从未支持的有效位输入，也不声称冻结模型已经学会空槽语义；保留分支和灰/黑对照就是验收这一适配。

## 共同随机数与终点

推理种子由公开的分支前观察、历史和事件哈希、原指令的摘要以及请求序号构造，不使用候选、分支条件、目标真值或恢复后的 timestep。同一父状态的 K/D/R 在未来相同请求序号使用同一随机种子，允许轨迹分歧后请求次数不同。此轮实际只测 K/D；R 的物理续接尚需后续验收。仍会重置服务端缓存并核验服务端返回的种子。
