# 固定工位回看控制器的输入与适用范围

本轮控制器用于 `multi_cue_versions_v1` 的容量先导。它在测试回合中不读取物体真值，但不是通用视觉运动策略，也没有调用 EventVLA 权重。

## 校准与测试分离

只在 seed 424242 上运行专家，分别记录四个槽位的开盖、观察、关盖及回到起点动作，形成一个不可变的共享动作库。校准使用专家物体几何属于离线示范；记录包含电机驱动序列、观察时刻及机器人起始关节状态。

测试 seed 为 200000、200001、200002，与校准分开。每种记忆方法和每个测试 seed 都加载相同四份动作文件，校验文件哈希，不重新生成针对该测试场景的专家轨迹。颜色改变，工位几何不变；该验证不代表新布局、移动目标或遮挡泛化。

## 控制器可用的输入

| 输入 | 来源与用途 |
|---|---|
| 公开槽位指令 | 决定调用哪个已校准动作；不读取真实目标所在位置 |
| 机器人关节位置 | 检查是否处于校准起始范围，关节 PD 驱动提供执行反馈 |
| 头部 RGB | 观察时读取颜色，结束时检查线索已重新遮住 |
| 公开版本更新记录 | 判断缺失证据是否仍能从当前环境恢复，不包含颜色答案 |
| 尚未淘汰的合法证据 | 从匹配槽位/版本的图像读取答案 |

`SharedRecoveryController` 不接收环境对象、seed、演员列表、物体位姿或答案。执行适配器只负责机器人驱动、仿真步进和经过白名单复制的观察。

测试观察与回看阶段，把 `inspect_cover`、`grasp_actor`、`place_actor`、位姿构造、oracle 关键帧及左右规划接口替换为立即报错的函数。任务评测器仍可在控制器输出答案后读取真值计分，但这些结果不返回控制器。此机制是接口审计，不是操作系统级隔离。

## 一次回看的流程

1. 查询匹配的保留证据。如果没有可读答案，查公开版本记录。
2. 旧版本已经被覆盖时弃答；当前版本仍可访问时，选择公开槽位对应的共享动作。
3. 机器人起始关节偏差超过 0.15 rad 时拒绝执行。当前版本不含自动重新规划、物体位姿修正或视觉伺服。
4. 执行固定驱动序列，在校准时刻取得 RGB 并读色；随后关盖并验证线索不再可见。
5. 输出答案。回看图像作为本次当前观察使用并释放，不在有界记忆之外保存颜色或图像副本。

八次查询互不重复，查询阶段保持历史库不变。所有方法使用同一触发器、动作库和 RGB 读色器。历史读取最多一张图像；完整存档可保存全部八张，结构化记录可保留全部可观察颜色，明确报告其存储权限差异。

## 本轮能支持与不能支持的结论

可以检验：固定工位下，没有测试场景真值规划时是否能可靠开盖回看；有限容量是否导致历史证据自然丢失；共享回看能否补救仍可访问的证据；最早保留、动作规则和存档对照是否已足够。

不能据此宣称：已验证通用非特权机器人策略、已完成 EventVLA 的缓存删除审计、已证明动作输入的独立价值、已学会不可逆机器人操作，或已获得端到端 VLA 任务成功率提升。当前最终提交是颜色回答，公开版本更新是装置命令。完整模型和更广泛的动作任务还需要独立验证。
